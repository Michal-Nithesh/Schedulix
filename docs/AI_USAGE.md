# AI usage report

## AI tools used
- GitHub Copilot as a coding assistant

## What was asked from AI
- Architecture scaffolding for a full-stack timetable project
- Initial backend generator and validator design
- Seed data preparation and timetable constraint logic
- API route scaffolding and project documentation

## Most useful prompts
- "Set up a monorepo with React + Vite frontend and Express backend for an intelligent timetable generator MVP."
- "Design a timetable generator that validates hard constraints and explains impossible schedules."
- "Create realistic academic seed data and tests that cover conflicts and valid generation."

## Code generated by AI
- Project scaffold and workspace structure
- API layer and scheduling algorithm modules
- Seed data and unit tests
- Documentation files

## Code modified by developer
- Constraint logic and feasibility checks were adjusted to match realistic classroom capacity and slot availability.
- Test expectations were corrected to reflect actual seed-data assumptions.
- Endpoint wiring and validation were tightened after test-driven verification.

## Incorrect AI output
- Initial generator logic assumed all room slots and faculty availability were feasible without checking real room constraints.
- A few tests used impossible or unavailable assumptions that did not match the actual seed data.

## How the issue was identified
- The backend testing suite exposed failing cases in room availability, capacity, and valid scheduling.

## How it was fixed
- Added explicit room availability checks in the generator and validator.
- Corrected test inputs to match the actual schedule availability.
- Verified the final set of tests passes.
